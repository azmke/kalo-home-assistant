# Security

Please do not report security issues in public GitHub issues.

For vulnerabilities involving credentials, tokens, authentication, or personal resident data,
open a private GitHub security advisory if available. Otherwise contact the repository
maintainer privately through the contact method listed in the repository profile.

Do not include real passwords, access tokens, refresh tokens, cookies, or complete resident
responses in reports. Redact personal data and provide a minimal reproduction whenever possible.

The client keeps tokens and cookies in process memory only. It does not provide a keyring,
database, persistent session, or credential export.
